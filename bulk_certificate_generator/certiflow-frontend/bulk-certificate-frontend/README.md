# CertiFlow — React + Tailwind Frontend

Modern React frontend for CertiFlow, a bulk certificate management platform.

## Run

```bash
npm install
npm run dev
```

Open:

http://localhost:5173

The frontend expects the backend at:

http://127.0.0.1:8000

You can override it with:

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```
